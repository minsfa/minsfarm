# minsfarm

작성자: **MS-ykmin**  
개발자: **MS-ykmin**

## 개요

**minsfarm**은 소규모 농업 현장의 나무 재배, 생육 관찰, 센서 모니터링, 자동화, 로봇, 웹서비스를 단계적으로 실험하기 위한 농업 기술 프로젝트입니다.

이 프로젝트의 1차 마일스톤은 실제 농업 기반을 만들고 농업경영체 등록 준비에 필요한 실행 체계를 정리하는 것입니다. 이후에는 나무·묘목류 관리 경험을 바탕으로 토양수분, 온습도, 사진 기록, 생육 모니터링, 자동관수, 웹 대시보드, 로봇·드론 모니터링 등으로 확장합니다.

| 작목 방향 | 관상수, 소형 수목, 밀원수 후보, 포트묘 등 관리 가능한 나무 중심으로 실험합니다. |

| 자동화 확장 | 자동관수, 센서 알림, 웹 대시보드, 로봇 순찰, 드론 모니터링을 단계적으로 검토합니다. |
