# minsfarm

작성자: **MS-ykmin**  
개발자: **MS-ykmin**

## 개요

**minsfarm**은 선유동 농지와 해남 나무 사업을 기반으로, 농업 실행·스마트 모니터링·로봇·자동화·웹서비스를 단계적으로 실험하고 확장하기 위한 프로젝트입니다. 이 저장소는 단순한 농업 기록 저장소가 아니라, 나무 재배와 현장 데이터를 기반으로 하는 **농업 자동화 기술 저장소**를 목표로 합니다.

현재의 1차 방향은 선유동 331-5 및 331-2에서 소나무 등 관상수, 헛개나무 등 향후 해남 밀원수 후보, 올리브 등 포트묘 관리 실험을 진행하면서 나무 관리 경험을 축적하는 것입니다. 농업경영체 등록은 이 프로젝트의 최종 목적이 아니라, minsfarm을 실행 가능한 농업 기반 위에 올리기 위한 **첫 번째 스텝**입니다.

## 방향성

| 구분 | 내용 |
|---|---|
| 농업 기반 | 어머니를 경영주로 하는 농업경영체 등록 준비, 선유동 나무·묘목류 재배 증빙 축적 |
| 작목 방향 | 소나무 관상수, 헛개나무, 수국·목수국, 기존 관상수, 올리브 포트묘 등 |
| 기술 실험 | 토양수분, 온습도, 사진 기록, 생육 모니터링, 데이터 로깅 |
| 자동화 확장 | 자동관수, 센서 알림, 웹 대시보드, 로봇 순찰, 드론 모니터링 검토 |
| 장기 확장 | 해남 헛개나무·밀원수·양봉 협력 사업과 연결 |

## 운영 원칙

Google Drive의 gartech 폴더는 영수증, 사진, 작업일지, 일정표, 상담기록 등 **행정·증빙 원본**을 관리하는 공간으로 사용합니다. 이 GitHub 저장소는 웹서비스, 센서 코드, 자동화 로직, 데이터 구조, 로봇·드론 실험 문서 등 **기술 구현과 개발 이력**을 관리하는 공간으로 사용합니다.

따라서 minsfarm의 초기 목표는 다음과 같습니다.

| 단계 | 목표 |
|---:|---|
| 1 | 선유동에서 어머니 명의 지출과 나무·묘목류 관리 증빙을 축적한다. |
| 2 | 토양수분·온습도·사진 기록 등 최소 센서 기반 모니터링을 시작한다. |
| 3 | 작업일지와 센서 데이터를 구조화하여 웹서비스와 대시보드로 확장한다. |
| 4 | 자동관수, 현장 알림, 로봇·드론 모니터링으로 확장한다. |
| 5 | 해남 나무 사업과 연결 가능한 농업 자동화 모델을 만든다. |

## 현재 핵심 문장

> 농업경영체 등록은 minsfarm의 목적지가 아니라, 선유동에서 실제 농업 기반을 만들기 위한 첫 번째 스텝이다. minsfarm의 장기 목적은 나무 재배, 센서 데이터, 웹서비스, 로봇, 자동화를 연결하여 선유동과 해남을 잇는 농업 기술 프로젝트를 만드는 것이다.

## 저장소 상태

이 저장소는 초기 기획 단계입니다. 향후 센서 데이터 구조, 웹서비스 설계, 자동화 스크립트, 로봇·드론 모니터링 아이디어가 순차적으로 추가될 예정입니다.
